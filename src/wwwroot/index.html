How to create a Mermaid diagram

  1. Type or paste Mermaid syntax into the Mermaid source field.
  2. Check the live preview. If the syntax is invalid, open the Console for error details.
  3. Zoom or pan to explore the diagram. Use preview controls to add nodes, connect them, edit labels, or choose colors.
  4. Use Undo and Redo to revisit edits, or switch between light and dark themes.

Choose Data Flow Diagram Mode for entity, process, data-store, and labeled-flow helpers. A starter template and editable legend help explain the meaning of your diagram.

Mermaid flowchart examples

Paste this example into the editor to draw an authorized administrator:

flowchart TD
    Admin["Authorized administrator"]

This example shows a decision and two possible paths:

flowchart TD
    Start["Receive request"] --> Approved{"Approved?"}
    Approved -->|Yes| Process["Process request"]
    Approved -->|No| Reject["Reject request"]

Use a subgraph to group related steps while keeping each node individually editable:

flowchart LR
    User["User"] --> App
    subgraph System["Application"]
        App["Process request"] --> Store[("Data store")]
    end

Share a diagram with a link

Click Copy diagram link to create a self-contained snapshot. Opening it restores the exact Mermaid source, including comments and whitespace, and the Standard or Data Flow editor mode. Compressed, URL-safe encoding keeps larger diagrams shorter without changing their source. Later edits do not change an already copied link.

Links are not encrypted: anyone with a link can read the diagram. Avoid sharing sensitive information. Very large diagrams can still create URLs that exceed limits in browsers or messaging apps.

Does the editor need JavaScript?

The interactive editor uses Blazor WebAssembly and loads Mermaid in your browser. JavaScript and WebAssembly are required for editing and previewing diagrams.
